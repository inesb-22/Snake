#How to Run

- Download and install Processing.
- Open Processing, click on the mode drop-down at the top right (default is Java), select Add Mode..., search for Python Mode, and click Install.
- Click the green < Code > button at the top of this GitHub repository and select Download ZIP. Then extract the .zip file on your computer.
- Open Processing, select Python Mode in the top right corner.
- Open the extracted main.py file.
- Click the Run button.

# 🐍 Snake Game

A classic, polished Snake game built using **Processing (Python Mode)**. Features custom vector graphics, smooth grid movement, dynamic speed scaling, collectibles, and lethal hazards.

---

## 🎮 Features

- **Custom Snake Rendering**:
  - **Dynamic Head**: Rendered with eyes and a red forked tongue that points in the direction of movement.
  - **Pointy Tail**: Tapered tail segment that automatically rotates based on movement direction.
- **Game Mechanics**:
  - 🍎 **Apples (Bonus)**: Increase length, score +1, and speed up gameplay.
  - 💀 **Skulls (Malus / Hazard)**: Lethal obstacles! Crashing into a skull ends the game immediately.
  - 🧱 **Border & Self-Collision**: Hitting the playing wall or biting your own body results in **Game Over**.
- **Score System**: Real-time score counter and performance-based end-game feedback messages.
